# 三图的证据与讲法

格式：每图PNG/PDF/SVG；10.5英寸演示画布。所有数量为固定情景或回顾性成交额代理，无统计误差棒；190状态×4配置×3深度不是2,280个独立市场样本。

## C01_capacity｜反馈没有改变资金容量边界

- 目的：直接回答多轮反馈相对一次冲击多贡献多少。
- a：Equal、d=1的190个月度参考资本上界，单位十亿美元。三条曲线完全重合，采用不同线型显示。
- b：4种原配置×3档深度各自的最大配对容量折减，均为0%；虚线是运行前10%材料性标准。
- 解释：没有新增容量约束，主门槛失败。不能把资本界叫真实安全资金规模。
- 源表：paired_capacity.csv、summary_metrics.csv。

## C02_activation｜成交量约束先绑定，损失未触发反馈

- 目的：解释零增量，并展示全状态而非挑选有戏剧性的危机图。
- 行为4配置×3档深度，列为190个月度状态；单元格是成交量上界的一次冲击NAV损失百分比，包含费用。
- 完整2,280格最大1.79158%，低于固定2%触发线。色标上界取预先阈值2%，nearest显示不插值，不删低损失状态。
- 解释：结合资金—损失单调关系，可保证当前成交量可行域内反馈不激活。该充分条件只针对给定自冲击模型，没有外生新闻/外部基金。
- 源表：capacities.csv；充分条件推导与检查记录另存。

## C03_volume_replay｜普通成交量保守基线的代价与作用

- 目的：展示普通成交量不确定性和资本利用的取舍，不包装成物理增量。
- a：Equal主配置下，189个有未来3日的截面；三个模型的均值ADV方案相同，超限142/189=75.13%；过去成交额20%分位参照62/189=32.80%。末端1个无未来截面保留为缺失。
- b：保守方案逐月部署资本相对均值ADV资本界，平均72.90%。全部189个值保留，无误差带；不是概率保证或最优策略。
- 解释：较少资金换得更少成交额代理超限，不能称实测滑点、真实订单失败或盈利改善。Equal之外四配置/完整数值均保留于源表。
- 源表：volume_replay.csv、volume_replay_summary.csv。
