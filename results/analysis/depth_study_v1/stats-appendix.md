# 深化研究统计附录

## 实验单位与分离

10 次完整研究相互独立；每次重新生成 420 个网格窗口和 72 个未见 rho 窗口，每窗 256 期。训练／验证／测试为 252／84／84；参数网格 rho={0.4,…,1.6}、步长 0.2，a={0.05,0.1,0.2}；未见值为 {0.5,0.7,0.9,1.1,1.3,1.5}。推断输入不含 rho、a、种子或划分字段。

监督方法各使用同一验证预算，12 个 RBF 超参数候选；预处理只拟合训练集，选参只看验证集，不重拟合测试数据，不裁剪 RBF 预测。物理估计器不训练，用已知 N、u 及精确有限图概率表达构造的曲线。两者使用同一模拟接口知识，训练需求不同。

## 主统计

汇总以每次研究的测试 MAE 为一行，n=10。报告均值、run SD、9,999 次 run bootstrap 均值区间。统一复用同一组重采样 run 索引，使严格不变方法的相同数据不会因 bootstrap 随机数不同呈现假变化。区间仅覆盖本研究固定参数网格和数据生成程序下的实验重复，不包含真实市场模型误设。

三个事先锁定的新研究对比：原尺度 joint−return；原尺度 joint−volume；双倍尺度 shape-joint−joint。配对差保留同一研究内的配对；符号检验以 10 次研究为单位，双侧检验胜率 1/2。它不要求误差正态，但不等于平均差零假设。三项 p 都为 0.001953125；Holm 后均为 0.005859375。详细配对标准化效应、差 SD 和区间见 results/tables/depth_study_v1/run_contrasts.csv。

| 对比 | 平均差 | run SD | 95% 配对 bootstrap 区间 | 左方法获胜 |
|---|---:|---:|---|---:|
| joint−return | −0.021647 | 0.003399 | [−0.023615,−0.019642] | 10/10 |
| joint−volume | +0.004818 | 0.001844 | [+0.003674,+0.005834] | 0/10 |
| shape-joint−joint，双倍尺度 | −0.226026 | 0.015278 | [−0.235022,−0.217169] | 10/10 |

平均误差相对变化取均值之比，不冒充各 run 百分比的均值。仅 10 次重训，bootstrap 和标准化效应仍可能不稳定；不宣称覆盖率已校准。

## 补充比较与估计器检查

未见 rho 上物理参照−joint 的平均差为 +0.0002315，95% 描述区间 [−0.0014803,+0.0021089]。这是补充比较，不新增一项主 p 值；也不是预设容差的等价检验。

380 与 460 位算术在五个核对点的 S2 转成浮点后相同；这不是所有概率绝对精确的证明。五个中点的反演插值误差最大 0.0003588；不作为全域上界。物理估计器将样本矩越出物理域的情况显式标志并返回边界，本轮 1,560 个测试／未见窗口均为 interior，未启用边界回退。

## 配对尺度压力

同一测试窗口 r 乘 0.5、1、2，V 不变；不是独立窗口数翻三倍。固定模型预测；不得用这些压力条件重新选参。volume、shape-joint 与物理矩预测变化阈值为 1e-10，实际检查全部通过。未知尺度在每个窗口内必须是共同乘法因子；没有覆盖时间变化的冲击或流动性反馈。

## 机制置换检验

利用旧的三个 iid 模拟序列，各 8,192 期。置换 V 保留两种边际的所有经验统计，零假设为同期 r² 和 V 独立。每个条件 4,999 次随机置换；加一公式单侧 p 分辨率 0.0002；三个 rho 为独立多重比较族，Holm 后 0.0006。对其他机制或真实自相关数据不直接适用。

联合约束 Z 的原始与一个匹配置换样本区间采用 1,999 次配对 period bootstrap，每次重估 q。它们是有限样本描述检查，不能当作已校准的一般模型选择器。rho=1 原始 Z 的名义 95% 区间不含零，保留该事实。看到这一偏离后，利用新研究已存在的独立样本做追加均值诊断；每个 rho、a=0.1 条件每 run 共 5,120 期，n=10。三种 rho 的平均 Z 区间均含零，但这不是证明零假设，也未搜索直到“通过”。追加声明见 docs/decisions/2026-10-27-depth-study.md。

q=1/2 时 Z 的三阶约束退化；满足 Z=0 是动作／聚合接口的必要条件，不足以唯一识别协调、ER 或临界性。有限 N 有界支持和已知零均值是当前模拟口径，真实数据需要重新建立检验方法。
