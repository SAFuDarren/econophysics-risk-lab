# 固定协方差后的尾部增量检验

**结论：已完成直接的增量检验；未建立羊群/渗流模型在真实市场上稳定超越强统计基线的证据。** 模型内可以确认协方差之外的尾部差异，但混合分布和经验方法也能捕捉相当部分，不能把这些差异归为物理方法独有的价值。

## 实际完成的比较

- 新下载九股票APD、XOM、JPM、CAT、MSFT、PG、NEE、JNJ、HD，共38,070条日线、4,230个收盘日期（含参考日期），截至2026-10-23。价格网格无补值/删值，与XNYS日历一致。
- 先冻结方法，再用旧行业ETF的2018—2019年选择统计参照，之后下载新股票。新增股票是外部资产留出，**不是新未来时间或未知危机**；固定存续公司池有生存者选择限制，不是历史指数选股回测。
- 每个资产池1508个历史评价日、204个2026评价日。两个池共享日期和美国市场环境，不能合并成3424个独立市场实验。
- 同一过去信息、零均值与协方差下比较九方法：Gaussian、椭圆Student-t、模式Student-t、模式波动混合、模式经验分布、FHS式过滤历史模拟、Herding及两个固定rho消融。主协方差EWMA126/.94，收缩协方差为完整敏感性。
- 所有预测场景的协方差相对误差低于1e-10；不能靠抬高波动/相关性制造尾部优势。所有未来观测与拟合输入严格分开，逐日预测和选择记录完整保存。

## 外部股票的冻结主结果

尾部指标为预测前波动标准化的5%下尾pinball；共同下跌指标为Brier，事件定义是至少3/9收益低于−2个预测边际标准差。越低越好。验证期选中的统计参照分别为Gaussian和FHS，未按新股票评价结果替换。

|评价期/指标|模型平均损失|参照平均损失|相对改善及未校正95%区间|结论|
|---|---:|---:|---|---|
|2020—2025 / 尾部pinball|0.12677857|0.12748910|+0.557% [0.053, 1.164]|Holm p=0.0772|
|2020—2025 / 共同下跌Brier|0.02075945|0.02078075|+0.102% [-1.244, 2.282]|Holm p=0.9004|
|2026 / 尾部pinball|0.10567953|0.10381383|-1.797% [-4.969, 1.045]|方向反转，区间跨零|
|2026 / 共同下跌Brier|0.00014125|0.00022183|+36.323% [20.955, 54.947]|0事件，仅能评价误报|

历史尾部的未校正区间略高于零，但两项主检验经Holm校正后p=0.0772，不达到0.05。不能把未校正区间改写为主族检验成功。共同下跌历史期只有32个事件、改善约0.10%，区间跨零。两项预设实际研究门槛均未通过。

2026股票池按该固定定义有0个共同下跌事件。36.3%的Brier相对下降来自更少误报，**不是抓住暴跌的准确率提高**；低概率Gaussian在该段的Brier还更低。不能降低阈值、改股票池或改日期来补造确认事件。2026行业ETF有2个事件，同样不足以稳定评价事件识别。

## 数值与协方差敏感性

原8192场景的历史改善很小，预设的16384场景抽查发现分位数数值变化不可忽略。因此保留原主结果，追加全部日期的高分辨率积分核验；没有重选候选、信息或统计参照。

|尾部分数口径，外部股票|2020—2025改善 [95%区间]|2026改善 [95%区间]|
|---|---|---|
|EWMA，8192场景|+0.557% [0.053, 1.164]|-1.797% [-4.969, 1.045]|
|EWMA，16384场景|+0.435% [-0.177, 1.155]|-1.665% [-4.731, 1.231]|
|EWMA，一维积分|+0.578% [-0.006, 1.262]|-1.720% [-4.602, 0.854]|
|收缩协方差，8192场景|-0.344% [-1.582, 1.113]|-0.241% [-0.938, 0.505]|

一维积分使用原已选形状的有限订单质量点与高斯残余CDF，不把可解析的正态分位交给场景抽样。它消除标量预测抽样误差，有限ER图/动作库仍是近似。高分辨率和积分核验的历史区间都跨零；2026仍反向。追加核验不是第二个独立市场样本，不能从不同分辨率中选择最有利结果。

## 临界性是否额外必要

用相同六个非高斯候选加Gaussian off，比较rho固定1.0与固定0.6，其他信息/协方差相同：

|外部股票，5%尾部|rho=1相对rho=0.6改善 [未校正95%区间]|
|---|---|
|historical_test|+0.622% [0.188, 1.079]|
|confirmation|-1.319% [-3.516, 0.366]|

历史期存在约0.62%的条件性小幅改善，2026反向；它是探索性消融，不构成真实市场临界点识别，也没有跨时段必要性证据。拟合rho不等于真实交易者连接度。

## 模型内证据：协方差不足，但物理不是唯一解释

六种真分布严格匹配相同经验协方差，各用50,000场景计算风险。下表的数值是模型内MC点估计，不是市场参数。

|真分布|95%VaR损失倍数|99%ES损失倍数|共同下跌概率|
|---|---:|---:|---:|
|Gaussian|1.642|2.639|2.302%|
|StudentT-5|1.567|3.512|2.920%|
|FactorMixture-p0.05-ratio6-k0.75|1.303|4.432|1.638%|
|Herding-rho0.6-q0.05-k0.75|1.605|3.203|2.514%|
|Herding-rho1.0-q0.05-k0.75|1.330|4.412|2.198%|
|Herding-rho1.4-q0.05-k0.75|1.040|4.753|2.352%|

例如相同协方差下，临界附近羊群例子的99%ES由高斯的2.639σ变为4.412σ，约高67.2%；通用波动混合的ES几乎相同。这是“风险未被二阶矩确定”的量化例子，**不是羊群法相对统计法的预测改善**。95%VaR反而可能变小，说明不能把临界性和所有风险阈值的单调上升混同。

每个真分布另有20次独立训练重复、每次504期。羊群真值下，物理模型可明显胜过高斯，但波动混合/FHS也捕获大部分增量；高斯、t和混合真值负对照均保留。区间以训练重复为单位，条件于共享的大测试库，不能把50,000场景当50,000次独立模型研究。完整九方法见synthetic_metrics.csv、synthetic_paired_effects.csv。

## Claim Candidates

- Claim: 相同协方差不能确定尾部风险。
  - Source evidence: synthetic_truth.csv、synthetic_ccdf.csv、T01。
  - Allowed wording: 在声明的六种受控真分布中，协方差匹配后尾部仍不同，通用混合可产生类似极端损失。
  - Forbidden stronger wording: 所有真实共同暴跌来自临界羊群；协方差方法没有任何用途。
  - Uncertainty: 有限图/动作库与有限测试分布；不声明文献首创。
  - Next check: 成员复核假设和匹配精度。
  - Decision: keep, model-scoped.
- Claim: 羊群尾部模型有真实市场增量。
  - Source evidence: contrasts.csv、mc_full_contrasts.csv、analytic_tail_contrasts.csv、T03/T04。
  - Allowed wording: 外部历史有约0.56%的名义点改善，主族校正及数值敏感性不支持稳定优势，2026方向反转。
  - Forbidden stronger wording: 已确认风险预测改善；临界性带来可部署的经济收益。
  - Uncertainty: 预定义外部资产但已知历史环境，日块区间近似且未重训全部过程。
  - Next check: 成员复核及未来真正未见时间的数据，而不是在当前留出上继续调网格。
  - Decision: weaken; stable-advantage claim rejected by this experiment.
- Claim: 2026共同暴跌预测改善36%。
  - Source evidence: metrics.csv、contrasts.csv、T05。
  - Allowed wording: 0事件段中相对FHS的误报损失较低，但Gaussian等参照更低；无法评价抓暴跌。
  - Forbidden stronger wording: 命中率/召回率提高36%；证明不会发生崩盘。
  - Uncertainty: 0事件不能估计检出性能。
  - Next check: 保持事件定义收集未来事件，不能按结果改阈值。
  - Decision: reject detection claim.
- Claim: rho=1是市场最优或真实临界点。
  - Source evidence: critical_ablation.csv、逐日law选择、T04。
  - Allowed wording: 模型形状消融历史有小幅差异，但2026不延续。
  - Forbidden stronger wording: 已识别市场临界性或唯一羊群机制。
  - Uncertainty: 第一模式加载、对称独立动作、固定N均是模型假设。
  - Next check: 需额外可区分机制的观测/干预，不以学习器分数代替因果识别。
  - Decision: reject structural-identification claim.
