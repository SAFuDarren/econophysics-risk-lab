Start with the model checks从模型核验开始

The core model and exact theory checks use the Python standard library. Run from the repository root.核心模型与精确理论核验使用Python标准库；从仓库根目录运行。

python scripts/reproduce.py --profile quick

This runs the exact theory checks, verifies the public source tables and exercises the model identities. Outputs go into a new local run directory.该入口运行精确理论核验、核对公开源表，并检查模型恒等式；输出保存在独立的本地运行目录。

python -m pip install -e ".[analysis,notebooks]"
python scripts/reproduce.py --profile notebooks

Reproduce the numerical studies复现数值研究

For the tested numerical environment, use requirements-study.txt. Plotting requirements are separate.经过实测的数值环境记录在requirements-study.txt；绘图依赖单独列出。

python -m pip install -r requirements-study.txt
python scripts/reproduce.py --profile forecast --destination /tmp/forecast-rerun
python scripts/reproduce.py --profile theory
python scripts/reproduce.py --profile site

The forecast profile reconstructs the fixed experiment in a new directory. It downloads the documented market archives and compares reproduced CSVs with the frozen tables.预测配置在新目录中重建固定实验：下载已有说明的行情归档，并将重新计算的CSV与固定源表比较。
