Observable market statistics, effective structure and risk市场观测统计、有效结构与风险

The inputs are log returns r, traded volume V, trade counts K and signed aggressor flow F. The inferential task is to extract risk-relevant size, directional and temporal structure from these observations. Shared trading decisions provide a microscopic explanation for the moment relations used in that inference.输入是对数收益r、成交量V、成交笔数K和有方向的主动成交流F。推断任务是从这些观测中提取与风险有关的大小、方向及时间结构；共同交易决策为这些矩关系提供微观解释。

Measure the inputs and define the size baseline测量输入，定义成交大小基线

F is aggressive buy volume minus aggressive sell volume. B measures execution-size concentration: at the same total volume, larger concentrated executions raise the sum of squares. Detailed executions allow B to be measured directly; macro-only deployment requires a specified size model and calibration to estimate it.F是主动买入量减去主动卖出量。B刻画成交大小集中度：总量相同，越集中成大单，平方和越大。完整成交记录可以直接测量B；仅使用宏观量部署时，需要给定大小模型并校准估计。

Under independent symmetric execution signs, the size baseline sets the reference flow second moment. The centred ratio G compares observed dispersion with that reference. Together with mean flow, size concentration and persistence, it gives an effective statistical description for the risk map. Interpreting it as group susceptibility additionally requires a participant/execution map and mark assumptions.在独立对称成交方向假设下，大小基线给出参考成交流二阶矩。中心化比值G比较观测离散程度与该参照；结合平均成交流、大小集中度和持续性，可形成进入风险映射的有效统计描述。若进一步解释成群体易感性，还需参与者与执行单位的对应及大小标记假设。

The same-window identity shows exactly what information the decomposition contains. Dynamic restrictions—such as faster activity changes and slower amplification—specify how the estimated structure is carried into a forecast. Their value is assessed against direct-flow and equally informed statistical controls.同窗口恒等式明确了这一分解所包含的信息。活动变化较快、放大变化较慢等动态约束，进一步规定如何将估计结构延续到预测；其作用通过直接成交流及同信息统计对照检验。

Shared actions become squared-size risk共同动作形成规模平方风险

An ER graph H has N traders and independent edge probability p. The expected mean-degree parameter c is the original project parameter ρ. It is an ensemble expectation; the realized mean degree of one graph can fluctuate.ER图H含N名交易者，每条边以独立概率p存在。期望平均度参数c对应原项目参数ρ；它是总体期望，单张图的实际平均度可以涨落。

Every connected group C, with size sC, shares one action ξC. Sell, inactivity and buy have probabilities q/2, 1−q and q/2. Different groups choose independently. The code uses a = q/2.每个大小为sC的连通群体共享一个动作ξC，卖出、不交易和买入概率分别为q/2、1−q、q/2。不同群体独立选择。代码使用a=q/2。

With full execution against an outside counterparty, signed orders change log price while absolute activity defines volume. λ is the price response and u is unit order size.在外部对手方全部成交的约定下，带符号的订单改变对数价格，绝对活动量定义成交量。λ是价格响应，u是单位订单量。

A permutation π applied to whole pairs gives (r′ₜ,V′ₜ) = (rπ(t),Vπ(t)). Every same-period empirical joint moment is preserved because the multiset of pairs is unchanged. The three HAR inputs use today, the past seven days and the past 28 days. The full model adds two activity, three price–volume coupling and two concentration features, for ten inputs.三个HAR输入分别使用当日、过去7日和过去28日。完整模型另加两项活动、三项量价联合和两项集中度特征，共10项。

Replace equal counts with effective trading weights将等量人数推广为有效交易权重

Under independent symmetric group actions, Var(ξC)=q and the cross terms vanish, recovering q times the squared-weight sum. Coupling can add positive or negative covariance. Effective weights describe directional trading scale, not identified numbers of people.群体动作独立、对称且Var(ξC)=q时，交叉项消失，回到q乘权重平方和。引入依赖后，协方差可正可负。有效权重描述同向交易规模，不直接对应实际人数。

Keep the memory left by splitting保留拆单产生的时间相关

One signed quantity split across several times can retain a common direction. That changes cumulative-flow variance through cross-time covariance. Next-day realized variance instead sums squared bar returns; its forecast must use the corresponding second moments rather than adding those covariance terms to the wrong target.同一方向的总需求分多次执行后，仍可能保留共同方向；跨时间协方差改变累计成交流的方差。下一日实现方差则是各时段收益平方之和，不能把前一种目标的协方差项直接加到后一种目标上。

Each node carries a positive trading weight and a direction in each layer. Its local field combines weighted neighbours, the other layer, inertia, an adapting past-direction trace and current order information. Turning a node changes its state; rewiring would be a separate rule.每个节点具有正交易权重，并在各层具有方向状态。局部影响由带权邻居、另一层、惯性、随历史调整的方向记忆和当前订单信息组成。公式给出发生更新尝试U=1时的条件概率。慢层每个时点以0.14的概率尝试更新，其余时候保持原状态。节点转向改变其状态，连边重连属于另外的规则。
