# Conditional coordination risk: website and report integration

The research line is aggregate observations → effective trading and response
states → future risk. Coordination changes flow covariance; accommodation,
price-impact recovery and return feedback determine how that covariance reaches
price risk. A positive mean intervention effect is distinct from additional
forecast information within an observed market.

The instrument separates fixed model interventions, privileged source-state
diagnostics, and an internal comparison on observed Bitcoin-derived risk. It
reads saved results; its controls do not generate new market forecasts.

The report adds the environment response and effective-state diagnosis in the
main body, with five new scientific figures. All 24 previous figures, original
tables and labeled mathematical relations remain. Earlier next-day and
eight-step forecast tasks retain their separate targets and evaluation sets.
