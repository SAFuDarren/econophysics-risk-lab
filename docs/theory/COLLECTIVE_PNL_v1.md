# 从羊群群体到策略P&L：观测投影与共同风险

这是对既有羊群模型的**条件观测扩展**，用于解释组合/因子暴露；未拟合真实ETF的微观交互，不是新的市场因果识别定理。2026-10-27在主实验结果后补充推导，未用于调参、选因子或替换主检验。

## 1. 多维观测的一个可检验模型

固定群体划分C及载荷b_C，令群体动作xi_C独立、对称，P(xi=±1)=q/2、P(xi=0)=1-q。多维观测为

$$Z=\sum_C b_C\xi_C+\epsilon,\quad E\epsilon=0,\quad\operatorname{Cov}(\epsilon)=D,$$

epsilon与群体动作独立。于是

$$\operatorname{Cov}(Z\mid\{b_C\})=q\sum_C b_C b_C^T+D.$$

若载荷/图随机，应在独立固定q和相应零条件均值前提下对上式取期望；不能把参数随状态相关变化时的式子原样套用。

给定在本期动作发生前已经确定的策略/组合权重矩阵W，P&L增量P=WZ，因此

$$\boxed{\operatorname{Cov}(P\mid W,\{b_C\})=q\sum_C(Wb_C)(Wb_C)^T+WDW^T.}$$

两条策略是否分散，取决于它们对共同动作模式的投影，而不只取决于名称、回看参数或累计曲线形状。共同载荷的正投影会增加协方差，反向投影可抵消；如果以降低整体敞口实现抵消，也必须报告敞口和收益，不能仅凭波动降低称为经济优势。

## 2. 与原S2放大的联系

取b_C=(lambda/N)s_C v，D=tau²I，固定q/lambda/N/v并按允许的图分布取平均，则

$$\Sigma=Kvv^T+\tau^2 I,\qquad K=q(\lambda/N)^2 E\!\sum_Cs_C^2.$$

原来的群体二阶矩S2仍控制共同波动强度。若v为全1向量，n个观测有共同相关

$$c=\frac K{K+\tau^2},\quad \frac{\lambda_1(C)}n=\frac{nK+\tau^2}{n(K+\tau^2)},\quad
\frac{\sigma_{\rm equal}}{\sigma_{\rm diagonal}}=\sqrt{1+(n-1)c}.$$

这给出一个清楚的正向联系：在原模型其余前提和载荷固定时，大群体放大可以变成共同波动和较弱的分散化。只有条件模型中的对应关系；真实相关增强也可能由共同新闻、持仓、异方差、市场结构等产生，不能据此恢复羊群网络或断言真实市场处于临界点。

同一K可以来自不同q、lambda及E S2组合，所以即使观测协方差很准，也不能分别识别这些微观来源；增加一个网络图或学习器并不消除这种乘积混淆。九行业相关网络的阈值连通不是无限规模渗流证明。

## 3. 真实策略的可计算统计解释

以过去数据得到资产协方差候选Sigma_t，以当前已知持仓得到W_t，策略风险候选为

$$\hat\Sigma_t^{PL}=W_t\hat\Sigma_tW_t^T
=W_t\operatorname{diag}(\hat\Sigma_t)W_t^T+
W_t[\hat\Sigma_t-\operatorname{diag}(\hat\Sigma_t)]W_t^T.$$

第一项是共享资产暴露项，第二项是资产协方差项。二者可有不同符号；长短组合可能抵消共同市场模式。它不是观测到的整个未来P&L协方差的精确分解，因为持仓、费用、均值和真实条件分布会变化，也不是唯一的因果来源划分。

对因子挖掘的作用是：将“新增参数版本”与“新增独立风险来源”分开，检查与已有候选的每日增量相关、联合亏损、持仓重叠和条件模式暴露。低相关本身不能证明正alpha，既有样例的亏损也不能否定所有动量/反转/防御因子。

## 4. 核验与证据

小群体动作的81种状态用有理数完整枚举，分别从动作分布和矩阵式计算策略协方差，验证两条路径一致。共同载荷示例仅是数学说明，不使用市场数据校准。见[补充核验](../../results/checks/us_equity_v1/collective_pnl_theory.json)。
