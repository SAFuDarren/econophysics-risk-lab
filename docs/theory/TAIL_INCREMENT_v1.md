# 协方差固定后，羊群模型还能预测什么？

证据类型：MODEL_CHECK／SIMULATION为推导与受控生成；REAL_DATA为冻结规则下的逐日评分。此扩展不识别真实交易者网络，不是新的金融市场定律或文献首创声明。

## 1. 为什么固定协方差仍有可检验空间

ER图G具有N=128个模型交易者，p=rho/(N−1)。各连通群体C共享独立对称动作xi_C，P(xi=±1)=q/2，P(xi=0)=1−q。q是活动率，不能与原潜在网络拆分的边保留率混同。

令Q=Σ_C s_C xi_C、S_j=Σ_C s_C^j，A=E[S₂]。原聚合接口给出

\[
\operatorname{Var}Q=qA,\qquad
\gamma_2(Q)=3\frac{\operatorname{Var}S_2}{A^2}
+\frac{1-3q}{q}\frac{\mathbb E S_4}{A^2}.
\]

因此控制二阶矩之后，群体四阶矩及群体二阶矩的涨落仍能改变尾部。标准化H=Q/√(qA)后方差为1，尾部形状仍随rho、q变化。临界性作用在群体分布；不能由“尾部较厚”逆推真实市场临界。

本实现用固定1024图×128动作/图的有限库近似ER动作分布，补入对称符号后标准化。标准化保证数值预测的二阶矩相同，但有限图/动作分布仍有Monte Carlo误差，不把有限库说成精确总体。

## 2. 多资产观测加载是额外假设

令Sigma_t为预测前、只用过去126个交易日得到的协方差，u_t为其第一特征向量，在白化坐标中取

\[
X_t=\Sigma_t^{1/2}\{\sqrt{k}u_t H+\epsilon\},\quad
\epsilon\perp H,\quad\operatorname{Cov}(\epsilon)=I-ku_tu_t^\top.
\]

则E[X_t]=0且Cov(X_t)=Sigma_t，对任意允许rho/q均成立。k是第一模式的非高斯方差份额，不是全市场羊群比例。真实ETF/股票收益未被证明遵守该加载；拟合rho是一个分布形状参数，不能称真实连接度、临界分数或交易者网络。

高斯、椭圆Student-t、同模式Student-t、同模式高斯尺度混合、经验模式和全向量过滤历史模拟，均使用同一协方差。场景最终去均值、白化并重新着色，以数值精度匹配Sigma_t；这是预测分布的已知矩规范化，不使用未来观测。

## 3. 组合尾部的一维表达

对固定等权w、s_t=√(wᵀSigma_t w)，组合标准化收益可写成

\[
Y_t=X_t^\top w/s_t=a_t H+\sqrt{1-a_t^2}Z,
\quad a_t=\sqrt{k\lambda_{1,t}}\,w^\top u_t/s_t,\quad Z\sim N(0,1).
\]

因此其超额峰度为a_t⁴ gamma₂(H)。所有方法的Var(Y_t)=1，分数差异来自尾部质量分布，不来自增加方差。该公式不保证所有分位风险随rho单调增加；少量大冲击可以使95%VaR较小而99%ES更大。

H的有限订单库有质量点h_j、权重pi_j。条件于该有限库，可不抽8192场景而直接积分：

\[
F(y)=\sum_j\pi_j\Phi\!\left(\frac{y-a_t h_j}{b_t}\right),\quad b_t=\sqrt{1-a_t^2}.
\]

VaR下分位v满足F(v)=alpha，ES为

\[
e=\frac1\alpha\sum_j\pi_j\left[a_th_j\Phi(z_j)-b_t\phi(z_j)\right],
\quad z_j=(v-a_th_j)/b_t.
\]

这消除标量预测场景抽样误差，但不消除有限ER库误差或模型误设。积分审计保持原模型选择、协方差和信息不变，不重选统计参照，也不替换冻结主检验。

## 4. 同信息与因果执行

在第t日收益产生之前，Sigma_t只读取t−126至t−1。历史白化创新z_s=Sigma_s^(−1/2)r_s和第一模式得分h_s=u_sᵀz_s都使用各自过去协方差。参数模型每21个交易日，在当时过去504个创新上以似然选固定候选；经验参照每天更新过去504个创新。所有方法可访问同一因果历史，更新规则属于各自冻结算法，不含额外成交量、新闻或未来收益。

参数族各含24个非高斯候选（羊群、模式t、模式混合）并可退回Gaussian；椭圆t为8个自由度候选加Gaussian。不能把拟合更好解释成机制已被证明，也不把候选数量当独立市场验证。

## 5. 风险评分

5%下尾pinball为
\[
L_\alpha(y,v)=(\alpha-\mathbf1\{y<v\})(y-v).
\]
收益与分位都按预测前已知s_t标准化，保持条件评分的正确方向；分数改善不是投资收益改善。

共同下跌事件是至少3/9资产满足r_i,t<−2√Sigma_i,i,t，Brier=(p_t−event_t)²。它是操作性事件，不是结构性市场崩盘；所有日都评分。若某段没有事件，Brier只能评价误报，不能评价命中或召回。

VaR/ES使用[Patton、Ziegel与Chen（2019），式6](https://public.econ.duke.edu/~ap172/Patton_Ziegel_Chen_JoE_2019.pdf)的FZ0：
\[
S_\alpha(y,v,e)=-\frac{\mathbf1\{y\le v\}(v-y)}{\alpha e}
+\frac ve+\log(-e)-1,\quad e\le v<0.
\]
FZ分数可为负，只比较分数差，不做可能失真的百分比。1%尾部与全部统计参照对照是次要探索，不能越过两项冻结主检验的Holm门槛。

## 6. 能证明与不能证明

同协方差下尾部差异证明“二阶矩不确定全部风险”；它不能证明“必须使用渗流”。通用重尾、波动混合或经验分布也能表达类似风险。真实市场额外价值必须用同信息、同协方差、留出评价的损失差支持；微观因果识别仍需其他可区分机制的观测或干预。

机制骨架来自[Cont–Bouchaud](https://arxiv.org/abs/cond-mat/9712318)；协方差匹配、共同模式加载与本轮审计是明确声明的项目扩展。没有加入时间反馈、泡沫积累、非对称恐慌、价格冲击非线性或量子模型。
