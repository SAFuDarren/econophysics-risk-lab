# 持久活动、时变响应与量价信息：机制增补 v2

证据分为预设受控模拟、总体矩推导、事后解释性构造和真实预测检验，不混用。以下没有将真实参与者活动率、流动性或拓扑识别出来，也不主张文献首创。

## 1. 最小动态扩展

保留原ER群体机制，网络每期仍独立、rho=1、N=128。仅允许活动概率q_t或冲击lambda_t具有持久状态：

$$r_t=\frac{\lambda_t}{N}\sum_i s_{i,t}\xi_{i,t},\qquad V_t=u\sum_i s_{i,t}|\xi_{i,t}|.$$

活动模型q_t在0.015/0.45两状态之间，平稳高状态概率0.15、转移持久性0.97，故qbar=0.08025。常数模型使用同样qbar。独立冲击模型令s_t为平稳标准差0.8、AR系数0.97的高斯状态，lambda_t=lambda0*exp(s_t-0.8²)，故E(lambda²)=lambda0²。四组的平稳均量与收益二阶矩在理论上匹配；有限路径不被强制归一到相同数值。

10条独立路径，每条8192期。常数/冲击模型共用相同图和动作，以隔离冲击变化；活动模型使用相同随机图和动作均匀数。第四组完整置换活动模型的(r,V)观测对，精确保留经验联合分布，改变顺序。路径级区间与真实市场日期块区间不是同一种误差。

## 2. 动态状态为何改变固定接口的推导

固定N、u，图分布与活动状态独立。令A=E S2、B=E S3、m_k=E(q^k)，则

$$\mathbb EV=uNm_1,$$
$$\operatorname{Var}(V)=u^2[(m_1-m_2)A+N^2(m_2-m_1^2)].$$

后一式的第二项来自Var(E[V|q])。它在固定活动率模型中不存在。因此不能把全部成交量方差反演成群体结构。

在固定lambda的活动混合下，

$$\operatorname{Var}(r)=(\lambda/N)^2m_1A,$$
$$\operatorname{Cov}(r^2,V)=(\lambda/N)^2u[(m_1-m_2)B+NA(m_2-m_1^2)],$$
$$\kappa_3(V)=u^3[(m_1-3m_2+2m_3)B+3NA\{m_2-m_3-m_1(m_1-m_2)\}+N^3(m_3-3m_1m_2+2m_1^3)].$$

原固定接口的Delta=E S3/(N E S2)不再普遍成立。用冻结参数计算：常数模型总体Delta=0.212115，活动混合为0.788145。rho仍为1，变化来自活动混合，不能把Delta变化自动叫作真实网络临界程度变化。

## 3. 受控实验支持什么

活动持久模型的平均幅度一期相关约0.381、成交量一期相关约0.853；独立冲击持久模型的幅度相关约0.179，但量相关接近零。常数模型两种相关都接近零。因此相似的幅度记忆可以有不同活动机制，量的时间结构有助于区分。

完整量价对置换后，Delta与所有经验联合分布保持不变，但幅度相关接近零。它证明同根经验联合分布不能替代完整的时间顺序信息；不是说两个过程的全时间序列概率律等价。

这些简单持久模型的Delta均未解释真实BTC 2025H2的负值。产生波动聚集和解释全部联合矩，是不同验收标准。

## 4. 事后解释性构造：活动与冲击补偿

这一节是在主预测和四臂模拟后增加的总体矩构造，未新增预测方法、未调参数匹配市场，不是预设模拟的第五个赢家。

沿用冻结的两状态q分布，取

$$\lambda(q)^2=\lambda_0^2\frac{\overline q}{q}.$$

则E[r²|q]=(lambda0/N)²*qbar*A恒定。因此其总体均量、收益方差与常数模型相同；若使用相同q、图和动作，其V过程也与原活动模型完全相同。可是

$$\frac{\operatorname{Cov}(r^2,V)}{\operatorname{Var}(r)}=u(1-\overline q)\frac BA,$$

而成交量三阶矩仍由上一节的活动混合决定。代入同一N=128有限图矩，得到

$$\Delta_{compensated}\simeq-2.16348.$$

这个构造具体说明：固定接口中的正Delta约束不能扩展到所有羊群机制。它没有解释真实Delta=-8.18的数值，也没有证明市场存在此补偿规则。小图精确分数枚举已核验协变公式，有限N总体值由既有高精度随机图递推计算。

## 5. 为什么机制诊断有信息，而预测增量仍可能小

同样的量变化可以来自参与强度、订单规模或响应尺度；活动与响应相互补偿时，量很有状态信息，却不必让未来收益方差更容易预测。在上述补偿构造、未来图/动作条件独立的前提下，对包含全部历史状态的过滤F_t，由迭代期望有

$$\mathbb E[r_{t+1}^2\mid\mathcal F_t]=(\lambda_0/N)^2\bar q A.$$

即使活动状态能被成交量暴露，这一特定条件二阶矩仍为常数；对未来多期平方收益和的条件期望也相同。它是所构造模型的目标特定结论，不是市场不可预测或成交量一般无信息的定理。

量价联合关系可排除某些解释，日内与滞后信息可区分动态结构，但这不等于每天都能稳定改善预测。真实v2的新增数据检验对此独立验收，不以机制图的成功替代预测成绩。

群体协调骨架参见[Cont–Bouchaud原文](https://arxiv.org/abs/cond-mat/9712318)；时间变化的交易响应动机参见[Bouchaud等](https://arxiv.org/abs/cond-mat/0307332)。[Cont–Kukanov–Stoikov](https://arxiv.org/abs/1011.6402)研究盘口订单流失衡；本项目只有成交K线与主动买量，因此不把I=2*takerbuy-V称为完整盘口OFI。上述具体状态扩展和消元构造由本项目明确给出。
