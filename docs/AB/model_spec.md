# 羊群／渗流量价基线：模型与理论接口 v1

状态：已实现并通过 foundation_v2 的实现检查，待另一位成员复核。协议沿用 PC5253-ABCD-1.4；以下细化既有模型，不改变 AB／CD 范围。模型关系是本组接口下的推导，不作为文献新颖性主张。

完整理论增补见 [理论基础与可识别性](../theory/FOUNDATIONS.md)：包含本接口的一般证明、课程渗流推导、固定图与随机混合的不同识别边界，以及精确反例。这里仍保留原有简要接口定义。

## 1. 观察对象与隐变量

节点是交易者，边是当期协调关系；连通分量内共同动作，分量之间独立。每个观测区间独立生成 $H_t\sim G(N,p)$，$p=\rho/(N-1)$。实现要求 $N\ge2$、$0\le\rho\le N-1$。

每个分量 $C$ 的动作 $\xi_C=-1,0,+1$，概率分别为 $a,1-2a,a$，$0<a<1/2$。$u>0$ 为每个活跃个体的订单量，$\lambda>0$ 为价格响应。主要恢复目标是 $\rho$；$N,u$ 在主比较中固定，$a,\lambda$ 的已知／变化条件需单独记录。

每个学习样本是一整段独立生成的窗口。可观察数据是同频收益和量，标签／种子／群体／边数另存；不能把隐变量 CSV 传入特征函数。

## 2. 成交执行与 OHLCV

每个活跃个体提交数量 $u$、方向 $\xi_C$ 的单位订单，外部简化对手方全部承接。单位订单随机排列，成交后 log 价格增量为 $\lambda\xi_C/N$。在更新后的价格记这一笔成交，数量只计一次：

$$r_t=\frac{\lambda}{N}\sum_C s_C\xi_C,\qquad
V_t=u\sum_C s_C|\xi_C|.$$

这里净方向指本组主动订单；真实每笔成交的买卖双方数量相等，不能把全市场买量减卖量解释为该净方向。对手方库存／现金变化与主动交易者相反。它是简化成交器，未实现订单簿、报价或流动性约束。

O 为前期收盘；H／L 包含开盘及全部成交后价格；C 为最后价格；D 为成交价格乘数量求和。无成交时 O=H=L=C，V=D=0。模拟时间仅是区间编号，不自动等于真实 5 分钟。

同一群体的单位订单会与其他订单随机混排，避免把群体整块订单大小变成额外标签。该随机路径给出一致 OHLC；在此执行器下，给定净方向与活跃人数，路径的条件分布由随机排列决定，不能据此宣称模拟了真实日内微观结构。

## 3. 固定图的可核对理论关系

设 $q=2a$、$M_2(H)=\sum_C s_C^2$。动作满足 $E\xi_C=0$、$E\xi_C^2=q$，不同分量独立，因此：

$$E[r\mid H]=0,\quad E[V\mid H]=quN,$$
$$\operatorname{Var}(r\mid H)=q(\lambda/N)^2M_2(H),$$
$$\operatorname{Var}(V\mid H)=q(1-q)u^2M_2(H),\quad
\operatorname{Cov}(r,V\mid H)=0.$$

最后一式来自买卖对称：$E[\xi_C|\xi_C|]=E\xi_C=0$。所以原始有符号收益与量的相关接近零并不意味着没有协调；核心特征采用 $|r|$ 与量的相关。相关也不自动证明因果机制。

每期重采样图时，因为条件收益均值和条件量均值均不随图变化，上述方差公式中的 $M_2(H)$ 替换成 $E_H M_2(H)$ 即得总体关系。静态逐期独立模型没有自动产生波动聚集或泡沫积累的时间反馈。

实现检查用固定分组 [1,2,3,4]、N=10、a=0.17、lambda=0.02、u=1，50,000 次独立动作；每个矩按已知总体中心构造成样本均值，报告估计 SE。6 SE 判据是实现诊断，不是对所有科学主张的正式显著性保证。

## 4. 量能约束什么，不能预设什么

若 N、u 已知，且总体矩可准确获得，则 $q=E[V]/(uN)$。当 $0<q<1$：

$$E_HM_2=\frac{\operatorname{Var}(V)}{q(1-q)u^2},\qquad
\lambda^2=N^2u^2(1-q)\frac{\operatorname{Var}(r)}{\operatorname{Var}(V)}.$$

这些是本接口的总体矩约束，不是对未知人数、订单尺度和流动性的真实市场做唯一识别。

对已知 N、a、lambda 的 ER 家族，收益方差本身已随 rho 严格增加：用共同 Uniform 边变量耦合两个连接概率，增加边只会合并分量；两群大小 s、t 合并令 $M_2$ 增加 $2st>0$。N 有限且两个概率不同时，存在正概率发生这样的合并，故期望严格增加。由此，不能声称该已知参数条件下只有成交量才能让 rho 可识别。量价比较应检查有限样本效率，以及 a／lambda 干扰下的恢复条件。

不同参数造成相同方差只说明矩层面的混淆，不证明完整分布相同。有限窗口误差大或两样本检验未拒绝也不能证明结构不可识别。

## 5. 明确的内部拓扑边界

固定图若连通分量划分相同，动作分布及聚合 r、V 分布相同。四人链和四人星都只有一个四人群体，因此本接口看不到它们内部边的区别。单位订单随机排列的执行器也不会补回这些边信息。这是指定群体动作规则下的严格边界，不是“任何金融数据都不能识别任何网络”的结论。

## 6. 临界统计口径

最大群体比例为 $s_{max}/N$。全体 $M_2$ 包含巨型群体，不能把它的单调增加当作临界峰。有限群体统计另排除一个最大分量：$\chi_f=\sum' s^2/\sum' s$，若无剩余分量，记缺失，不能记零或删除不报。相同最大值并列时排除一个，规则固定。

ER 无穷规模阈值 rho=1；有限 N 的扫描只能展示有限规模过渡。图的重复单位是独立网络，不是同图中的每个群体。

## 7. 实现与来源边界

共用实现为 `src/econophysics/model.py`，特征为 `features.py`。主模拟使用独立的图、动作和执行随机流；同一配置／种子可复现，种子不进入学习输入。ER 生成器使用缺失边的几何跳步，另用 N=3 的闭式恒等式 $E M_2=3+6(p+p^2-p^3)$ 核验。

群体协调与聚合机制参考 [Cont–Bouchaud 原文，Section 4](https://arxiv.org/html/cond-mat/9712318v2)。本组全成交对手方、单位订单路径、量和额定义是本项目明确添加的接口，不能归给原论文。
