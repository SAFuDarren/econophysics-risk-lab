# 深化研究的锁定问题与图形合同 v1

这是一轮原模拟之后、由理论和文献触发的新研究。新配置在新结果产生前写入，不冒称整个项目的预注册；旧模拟与交接不改。

## 三个问题

1. 收益＋量的恢复增益在重新生成数据并重训 10 次后是否仍成立？以完整训练实验为重复单位；不把 840 个测试窗当作 840 次重训。
2. 价格尺度漂移能否用明确的尺度不变表示消除？固定使用均值绝对收益和两个分位数除以收益标准差；丢弃标准差这一尺度坐标，保留量与相关。不给训练器输入尺度倍数。
3. 只匹配收益和成交量各自分布是否足以验证协调机制？固定使用量序列置换对照；它精确保留两种边际分布、破坏同期配对。检验联合矩与新推导的网络分布无关矩约束。

另加入无监督标签的物理矩参照：有限 N 的 ER 连通概率递推给出 E S2(rho)，成交量矩求逆。递推用 380 位十进制计算，另作更高精度和独立图枚举核对；它是高精度数值，不是符号精确。求逆有网格插值误差，边界事件必须显式报告。学习器仍用共用实现的训练内预处理／验证选参，不重拟合测试集。

## 统计和结论

主比较见 configs/depth_study_v1.json。报告 run 均值、SD、run bootstrap 区间、配对差和符号检验；10 次重复仍然有限。符号检验检验获胜概率，不冒充平均误差检验。量置换检验使用 iid 模拟，不能直接套到真实自相关行情。

使用已确定的 Python 后端，白底、色盲安全、PDF/SVG/PNG，完整源表、图注和 QA。图号 D01–D03 为深化增补，不占用原协议 F 图。

- D01：重复研究能否支持稳定的恢复结论？a 为各方法 10 次 MAE，b 为预设配对差，含 run bootstrap 区间。原始点全部显示。
- D02：尺度稳健性是否可由表示设计解决？展示三种 lambda 倍数下的恢复误差，完整独立重复和区间；不预设尺度不变表示在无漂移时最优。
