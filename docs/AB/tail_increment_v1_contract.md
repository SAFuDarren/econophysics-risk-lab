# 协方差之外的尾部增量：冻结契约

冻结日期2026-10-27；在新九股票价格下载前冻结。机器定义以configs/tail_increment_v1.json为准。旧行业ETF的全部历史已看，不能称本轮新盲测。新增九股票的本地原始价格在冻结时尚未下载；它是规则先定的外部资产留出，历史危机与宏观环境已知，不是新时间验证，也不是无生存者偏差的历史选股实验。

## 研究对象

检验在相同信息集、零条件均值、相同协方差预测下，独立ER羊群模型诱导的非高斯共同冲击，是否改善次日组合下尾与共同下跌的预测。真实市场的模型拟合参数只能称“模型形状参数”，不得称已识别真实交易者人数、临界点或真实羊群机制。

所有方法使用过去504个因果标准化的日收益向量。每个预测日的协方差只取之前126日，主口径固定为此前研究已选的EWMA126/.94；LedoitWolf126为完整敏感性。所有预测场景再校准为同一协方差，排除单纯提高波动或相关性造成的改善。不得用未来收益估计当日矩阵、样本均值、模型形状或标准化因子。

## 机制及统计参照

模型在每期生成ER图，rho=p(N−1)，群体共享买卖/不交易动作，活动率q（不同于旧潜在图拆分中的边保留概率），N128。聚合订单冲击经标准化后进入资产收益协方差的第一特征方向；其余方向和同方向残余为高斯。共同冲击的方差份额k固定网格，协方差完全匹配。

统计参照包括高斯、椭圆Student-t、同样第一模式加载的Student-t、同模式高斯尺度混合、同模式经验分布、全向量过滤历史模拟。Student-t与混合模型有与羊群模型相当的形状候选预算；允许精确Gaussian off。各模型每21日用同一过去窗口的似然选形状，不按评价表现择优。另保留rho固定0.6与1.0的等预算消融，检验收益是否真需要接近临界。

正向理论：S2=Σs_C²决定二阶矩，S4及S2涨落参与四阶矩；匹配S2对应的协方差后，尾部仍可不同。但这种差别也能被非物理的重尾或混合分布表达，必须与这些参照比较。真实多资产加载是假设扩展，不是原Cont–Bouchaud模型直接给定的市场定律。

## 评价及统计

固定九资产日等权组合，次日5%下尾pinball损失为主尾部指标；收益和预测分位同时除以预测前已知的组合波动。1%下尾及FZ0的VaR/ES联合分数为次要指标，FZ0比较分数差，不对可能为负的分数做百分比改善。

共同下跌定义为次日至少3/9资产低于各自预测标准差的−2倍，主指标为Brier。概率及实际事件全部保留，不能只在崩盘日评分。它是操作性共同下跌事件，不等于经济学上的市场崩盘。

各指标的强统计参照仅用旧行业ETF的2018—2019年选择，在新股票数据下载前另存选择冻结。主检验族为外部九股票2020—2025年的两个端点，20日配对圆形块、4999次、Holm校正；5/63日敏感性和2026年结果完整披露。研究单位为交易日，不能把9只资产或8192场景当重复。区间与检验是依赖/制度变化下的近似，不等于制度外泛化保证。

旧行业板块作为回顾性开发/评价数据，不能贡献“全新留出”的声明；外部股票预定义的滚动拟合可因果使用已经过去的评价日，属于walk-forward评估，不能访问当日以后。所有历史事件已知，新股票参数不按其评价结果调整。
