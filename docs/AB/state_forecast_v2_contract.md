# 机制与状态预测 v2：冻结契约

用户要求改进机制和特征，用新留出检验更稳定的实际增益。本契约与配置在新ETH及2026年10月数据下载前冻结；旧批次均不修改。

## 新数据的身份

旧BTC已看到2026-09-30，因此Q2/Q3只能作开发诊断。新增BTC 10月1–25为新时间检验，仅25日。新增ETH 2025至2026-10-25：2025训练、Q1选参、Q2/Q3为此前未看的资产留出，10月再作新时间检验。ETH与BTC同属加密市场、共享环境和日期，不能称为独立市场复制；回顾性的外部资产检验也不是当时真实上线记录。

## 改什么与为什么

固定活动率和冲击无法产生前轮观测到的时间结构。新增一个受控的持久活动状态与持久冲击模型，保留ER群体骨架；通过完整量价对的时间置换保留经验联合分布、破坏顺序，分开边际/联合矩与记忆。只检验这些机制可能产生什么，不识别真实交易者行为。

现实表示保留最近4小时波动/活动、成交笔数与平均单笔规模、主动成交方向持续性、价格对有符号主动量的无量纲响应代理。仅收益基线同步加入尾部、负向半方差和日内近期波动，防止把价格信息误算成量的贡献。响应代理不是盘口OFI、真实流动性或因果价格冲击。

## 预测模型

v2预设主损失改为QLIKE，以正值log-link Gamma准似然直接拟合RV的条件均值候选。log-MSE继续强制报告，不以改指标隐藏v1结果。分块惩罚分别收缩价格与成交通道，成交通道包含off选项；验证认为不值得用量时必须允许自动退回强价格基线。

365日目标窗口，每7日更新；同条件价格基线也更新。static控制只在评价段开始拟合一次。所有拟合、均值/方差标准化、滚动量和超参选择均只用当时已完成数据；每个资产只用自身Q1选参，不用另一资产未来标签选超参。

## 验收与统计

主比较为StateVolumeGamma-Adaptive对ReturnGamma-Adaptive。三组新评价分别报告、主近似块p作Holm三项校正。183日外部检验与两个25日检验绝不按总资产日简单合并。1/3/7日块敏感性，主7日；短留出的区间只能作为近似和初步证据。

预先定义研究门槛：外部资产QLIKE点改善至少5%、主区间高于零、log-MSE不恶化，新时间结果不矛盾；这不是通用业界标准。即使达到，由于新时间只有25日，稳定性和决策效益仍是初步结论；未达到则明确不足。风险预算比RV/forecast为理论诊断，没有实盘、成本、收益或资金配置建议。
