# 容量检验的成图约定

Python/matplotlib沿用既有后端，输出可编辑PDF/SVG与300dpi PNG。用于研究展示的10.5英寸宽画布，不宣称满足某期刊投稿尺寸。所有图属于REAL_DATA-conditioned SIMULATION或回顾性成交额代理重放，不是实盘效果。

- C01：回答“反馈改变多少容量”。左图显示190个月度主配置三方法的完整资本上界，重合必须标明；右图显示4配置×3深度的最大配对容量折减，并标明10%材料性门槛。无统计误差棒，全部为确定性状态描述。
- C02：回答“为什么反馈没有改变容量”。完整190×12状态热图显示成交量上界的一次冲击NAV损失，与固定2%触发阈值比较。深度范围不是置信区间；不按结果选择日期或隐去低损失状态。
- C03：回答“普通成交量约束的不确定性与资金代价”。主配置189个有未来3日的状态中，展示三方法重合的超限比例，以及简单成交量分位基线的超限/部署资本取舍。一个最终状态缺失保留；不用模拟图冒充实际执行效果。

每图只有一个结论，图注写清数据/条件、单位、样本定义、无误差棒的原因、缺失规则和允许解释。多面板在实际渲染后做plot-area对齐检查；最终PDF做字形与碰撞检查，再逐面板目视检查。源表不裁样本，不画虚构预测区间或“量子优势”。
