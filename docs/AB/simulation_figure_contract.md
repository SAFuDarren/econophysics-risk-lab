# 模拟研究出图合同

协议 ERL-1.4；后端沿用 Python/matplotlib。目标为研究报告和可复用仓库，非期刊投稿。原始观察不删点，不换种子；零值只因 log 坐标不绘出，仍保留概率分母和源表。

| 图 | 一个核心问题／证据 | 面板角色与边界 |
|---|---|---|
| F03 | 连接增加怎样改变宏观群体结构 | 最大群体比例与排除最大群体后的统计；每格 40 个独立图，点态 95% graph-bootstrap CI，有限 N 不等于精确阈值估计 |
| F04 | 有限群体大小分布怎样随连接改变 | N=512，按每节点群体数计密度；独立图 bootstrap，零计数不绘 log，不用群体当独立重复 |
| F05 | 收益尾部是否与指定有限幂律相容 | 原始离散 CCDF 与 xmin=4 的条件有限支持拟合；拟合优度和指数候选表共同解释，不从直线外观判定 |
| F06 | 人数与时间聚合怎样改变分布 | 系统规模与非重叠时间聚合两个不同尺度；标准化仅作形状比较，不称证明普适标度 |
| F10 | 同样样本加入成交量是否改善恢复 | 三种经典参照的主比较 + 预设 RBF 学习曲线；84 个独立测试窗口，条件于一次训练划分的分层 bootstrap CI |
| F11 | 价格尺度变化导致什么恢复边界 | 冻结 RBF 的压力曲线（同 84 个基础窗口）+ joint 误差分组图（每格 4 窗，描述性、SD 在源表）；volume-only 为事后明确追加的诊断参照，不冒充原始主比较 |

每图输出 PNG 预览及 SVG/PDF 矢量，宽 183 mm，字号不低于 8 pt。多面板使用最终几何对齐检查；PDF 做字号与碰撞审计，再逐图读图。学习 CI 不含重新训练的不确定性；不能把多个尺度的同源窗口计为新的独立重复。

最强允许结论围绕指定模型、有限参数网格和一次训练结果；不推到真实市场、量子优势、普适幂律或内部拓扑恢复。成员科学复核仍待进行。
