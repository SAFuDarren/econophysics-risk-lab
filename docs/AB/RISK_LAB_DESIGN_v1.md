# 联动风险实验室：界面与证据设计

用户：本组成员、课堂听众和复用分析的研究者。工作是检查遗漏、重复与配置权衡；不是生成买卖信号。目标是一份可离线打开、可携带的项目工具。

界面采用白/冷灰底、墨蓝文字和海蓝数据线：纸白#F8FAFC、墨蓝#182D39、海蓝#24647D、青绿#3D8274、赭金#B18A42、钢灰#687B8B；亏损以负号与语义文字同时表示，不仅依赖颜色。字体以系统中文无衬线为正文，数字采用等宽数形；不加载远程字体。

桌面为左侧参数/右侧主图；窄屏先参数后图，全部重排。开页即为一个真实风险窗口，不放装饰性卡片墙。四页依次为风险遗漏、因子筛查、组合配置、物理机制。独特视觉重心是“共同部分”的风险条、重复因子矩阵与群体图，而非通用仪表盘。

第一遍方案审查后，取消巨大百分比英雄区、全屏深色皮肤、等大指标卡和自动动画；使用一张主要关系图与紧邻的数值对照。四页各回答一个决策问题，交互更新不加入无意义过渡。

风险页：指定月末窗口、行业权重、估计长度；显示完整/对角风险、联动占比和图。反事实相关缩放与真实样本严格标注，显示边的规则不改变风险计算。

筛查页：训练期相关阈值、六条固定候选、完整每日相关矩阵；说明冗余规则基于训练相关与换手。新增规则为事后探索，不能称新盲测。展示保留代表后组合的真实数字，包括可能变差的结果；统计重建不当作alpha或可执行对冲。

配置页：相同成本口径，保留四个原参照和筛查等权。收益、波动、底层敞口、换手同时展示；可切换固定资本/验证期等风险缩放，不通过降低敞口制造“优势”。

物理页：固定种子ER图、群体动作、S2与条件方差，连接已运行的有限规模相变曲线。真实行业相关网络与模拟交易者网络是两种对象；不输出“真实临界分数”。

导出为当前对照的可读摘要，带数据日期、假设与来源批次。数字可追溯；工具不自动选择赢家。验收包括数学恒等式、原Equal配置一致、费用净额、无空选择/NaN、键盘操作、窄屏布局、四页截图和无网络离线运行。
