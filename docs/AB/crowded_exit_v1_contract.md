# 拥挤退出最小检验：运行前固定契约

本契约与[配置](../../configs/crowded_exit_v1.json)在新容量结果计算前固定。只复用既有六策略/九ETF、四种原配置，不下载市场、不重新搜因子、不覆盖旧批次。全部历史已查看，本研究为回顾性条件压力检验。

## 研究对象与固定参数

一个账户管理六条策略，按原保存配置合并到九ETF净持仓。不是六家外部基金；原策略指数单位须先换成美元敞口z，再按参考资金A缩放。初始减仓f=25%，期限H=3交易日，参与率alpha=10%，过去20日成交额/63日波动均不包含情景当日。费用5bp。资金是固定参考资本，不是从历史P&L推出来的真实基金NAV。

以深度D_i=d*0.4*ADV_i/sigma_i*sqrt(H)作为明示情景；主d=1，d=0.5/2为预设敏感性。0.4取自此前核对的Cont–Schaanning模型约定，不是ETF执行数据校准。一次冲击和反馈使用同一函数、深度、费用和净持仓。

## 价格、现金与减仓规则

情景开始时价格归一为1，带符号初始敞口X_i=A*z_i。累计减仓q对应p_i(q)=exp(-q*X_i/D_i)，长仓卖出压价，空仓回补抬价；初始现金C0=A−ΣX_i。逐笔连续价格路径的积分I_i(q)=∫0^q p_i(s)ds给出

\[
C(q)=C_0+\sum_i X_i I_i(q)-c_{fee}\sum_i|X_i|I_i(q),\qquad
E(q)=C(q)+(1-q)\sum_iX_i p_i(q),\quad L(q)=1-E(q)/A.
\]

现金留在账户，不把减仓当资本赎回或将返还资本误记为损失。累计冲击、剩余头寸和现金统一计算；反馈轮次不是新交易日，不重置深度或3日成交预算。无外生新闻冲击、无外部基金持仓假设、无冲击恢复假设。

反馈在损失超过参考NAV的2%后启动，每增加1个百分点损失多减5个百分点初始仓位：q_{k+1}=max(q_k,min(1,0.25+5*[L(q_k)−0.02]_+))，q0=0.25。它是固定的演示风控规则，并非已观测机构行为。损失上限5%同时约束一次冲击与反馈。

## 三种容量边界

- VolumeOnly：q=f，按原价格计的总订单≤H*alpha*ADV；只含同样5bp费用，无市场冲击。
- OneRound：q=f，加入完整价格/现金冲击，成交量约束与NAV损失上限均满足。这里的“一次”是一次计划减仓的完整成交路径，不是忽略执行价格的终点跳价。
- Feedback：沿固定规则得到收敛q，使用相同约束。非收敛状态视作不可行并单列。

容量搜索在解析成交量上界以内进行，不通过随意扩大杠杆制造级联。主效果为1−A_cap^Feedback/A_cap^OneRound；这是模型隐含容量折减，非准确率、避免损失或收益改善。

## 样本、比较与停止条件

取2011年起每个自然月最后可用交易日；2026-10为不完整月末截面，单列。全部四原配置与d=0.5/1/2保留。主对象Equal、d=1。五个既定日期用于直观案例，不能替换成结果最好日期；完整逐月源表保留。

事先固定材料性门槛：主对象容量折减≥10%须出现于至少两个不同自然年，才值得继续审查。该门槛仅是应用可行性标准，不是统计显著性、行业标准或实用效果验收。未通过即停止扩展，敏感性结果不能救活主检验。通过也不自动进入新市场、机构、模型或网站工作。

每月状态是描述性重复，不独立；同一状态下三方法为精确配对。确定性模型不计算虚假p值或将参数范围当置信区间；报告全部状态的分位数、最大值和事件数量。真实未来3日成交额只作代理约束重放，末端无未来数据记缺失；历史重放不称新盲测，较低超限率必须同时披露较低资金部署。
